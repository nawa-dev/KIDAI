บทนำและภาพรวมระบบ (Introduction & Overview)

KIDAI (คิดได้) คือแพลตฟอร์มการเรียนรู้และทดลองปัญญาประดิษฐ์ (AI Vision Studio) บนเว็บเบราว์เซอร์ ที่สร้างขึ้นเพื่อเชื่อมต่อความสามารถด้าน Computer Vision เข้ากับบอร์ดสมองกลฝังตัว KidBright32 โดยมุ่งเน้นการประมวลผลที่รวดเร็ว ปลอดภัย และไม่จำเป็นต้องติดตั้งโปรแกรมฝั่งเซิร์ฟเวอร์หรือคอมไพเลอร์ Python เพิ่มเติม

🔒 100% Client-side

รันโมเดลบนเบราว์เซอร์ด้วย TensorFlow.js และ MediaPipe ไม่มีการส่งภาพขึ้นคลาวด์

⚡ Direct Web Serial

ส่งผลลัพธ์ผ่านสาย USB เข้าสู่บอร์ด KidBright32 ทันทีที่ความเร็ว 115200 bps

🧩 KidBright Plugin

มีปลั๊กอิน ai_serial.zip รองรับการต่อบล็อกคำสั่งใน KidBright IDE ทันที

ข้อกำหนดของระบบ: ใช้งานได้บนคอมพิวเตอร์ที่ติดตั้งเบราว์เซอร์ Chromium-based เช่น Google Chrome หรือ Microsoft Edge (เวอร์ชัน 89 ขึ้นไป) พร้อมกล้องเว็บแคม และบอร์ด KidBright32 เชื่อมต่อผ่านสาย Micro-USB Data
2

การติดตั้ง Plugin ในโปรแกรม KidBright IDE

เพื่อให้บอร์ด KidBright32 สามารถรับข้อมูลผลลัพธ์การทำนายจาก KIDAI ได้ จะต้องติดตั้งปลั๊กอิน AI Serial Plugin ในโปรแกรม KidBright IDE ก่อน โดยมีขั้นตอนง่ายๆ ดังนี้:

STEP 1
ดาวน์โหลดไฟล์ปลั๊กอิน ai_serial.zip

คลิกปุ่มดาวน์โหลดบนหน้าเว็บเพื่อรับไฟล์ ai_serial.zip (ไม่ต้องแตกไฟล์ zip)

STEP 2
เปิดโปรแกรม KidBright IDE และเข้าสู่เมนู Plugins

ที่แถบเมนูด้านบนของโปรแกรม KidBright IDE เลือกเมนู Plugins > Install Plugins

STEP 3
เลือกไฟล์และรีสตาร์ทโปรแกรม

เลือกไฟล์ ai_serial.zip โปรแกรมจะทำการติดตั้งและรีสตาร์ท KidBright IDE ให้อัตโนมัติ

STEP 4
พบบล็อกคำสั่งกลุ่ม AI Serial

จะพบบล็อกคำสั่งใหม่ในแถบหมวดหมู่ Plugins > AI Serial สำหรับนำไปต่อกับบล็อกแสดงผล LED หรือควบคุมอุปกรณ์

// ตัวอย่างบล็อกคำสั่งที่ใช้งานบ่อย
  • • เมื่อมีข้อมูลจาก AI Serial มาถึง (Event Listener)
  • • อ่านค่าข้อความ AI Serial (String) สำหรับโหมดจดจำใบหน้า เช่น "Alice"
  • • อ่านค่าตัวเลข AI Serial (Number) สำหรับโหมดนับจำนวนนิ้ว เช่น 0 ถึง 5
3

โมเดลจดจำใบหน้า (Face Recognition)

โหมดจดจำใบหน้าพัฒนาขึ้นโดยใช้การผสมผสาน 3 เทคโนโลยี: BlazeFace สำหรับตีกรอบและ Crop เฉพาะใบหน้าจริง, MobileNet ในการสกัดคุณลักษณะ (Feature Vector 1024 มิติ), และ KNN Classifier ในการจำแนกประเภทแบบ Real-time

แนวทางปฏิบัติที่ดี (Best Practices):
  • จำนวนภาพตัวอย่าง: แนะนำให้เก็บภาพตัวอย่างประมาณ 8 ถึง 15 ภาพต่อคลาส
  • ความหลากหลายของมุมมอง: ขณะกดค้างถ่ายภาพ ให้หันศีรษะซ้าย-ขวา เอียงคอเล็กน้อย เพื่อให้โมเดลจำได้ทุกมุม
  • คลาสสำหรับพื้นหลังว่าง: ควรเพิ่มคลาส "ไม่มีคน" หรือ "พื้นหลัง" โดยการถ่ายภาพห้องที่ไม่มีคน เพื่อช่วยลด False Positive
  • เกณฑ์ความมั่นใจ (Threshold): ตั้งค่าเกณฑ์ความมั่นใจไว้ที่ประมาณ 70% ถึง 80% หากโมเดลมั่นใจต่ำกว่าเกณฑ์ จะถูกจัดเป็น "คนแปลกหน้า (Unknown)" ทันที
4

โมเดลนับจำนวนนิ้ว (MediaPipe Hands)

ตรวจจับและระบุตำแหน่งข้อต่อกระดูกมือ 21 จุดในรูปแบบ 3 มิติแบบ 60 FPS ด้วย MediaPipe Hands จาก Google พร้อมระบบนับจำนวนนิ้วที่ชูขึ้น (0 ถึง 5 นิ้ว) ที่รองรับทั้งมือซ้าย มือขวา และตรวจจับนิ้วโป้งได้อย่างแม่นยำ

รูปแบบข้อมูลที่ส่งไปยัง KidBright32:

เมื่อตรวจพบมือ ระบบจะส่งตัวเลขเดี่ยว เช่น "0", "1", ..., "5" เข้าสู่บอร์ดทาง Serial โดยตรง เพื่อให้นักเรียนนำค่าตัวเลขไปเปรียบเทียบในบล็อก If/Else ได้ง่ายดาย

5

การเชื่อมต่อ Web Serial API

Web Serial API เป็นมาตรฐานของ W3C ที่อนุญาตให้เว็บเพจสื่อสารกับอุปกรณ์ภายนอกผ่านพอร์ต Serial ได้โดยตรง:

Baud Rate ความเร็วสื่อสาร 115200 bps (8 data bits, no parity, 1 stop bit)
Auto-reconnect ระบบจำพอร์ตเดิมไว้ในเบราว์เซอร์ เชื่อมต่อให้อัตโนมัติเมื่อเปิดเว็บ

การแก้ปัญหาและคำถามที่พบบ่อย (Troubleshooting & FAQ)

Q1: ทำไมกด "เชื่อมต่อ KidBright" แล้วไม่มีพอร์ต COM ขึ้นให้เลือก?

1. ตรวจสอบว่าสาย USB ที่ใช้เป็นสาย Data หรือไม่ (สายชาร์จบางรุ่นมีเฉพาะขั้วไฟ ไม่มีสายข้อมูล)
2. ตรวจสอบว่าได้ติดตั้งไดรเวอร์ USB to Serial เช่น CP210x หรือ CH340 ของบอร์ด KidBright32 แล้วหรือยัง

Q2: เกิดข้อผิดพลาด "Port is already open" เชื่อมต่อไม่ได้

หากเปิดหน้าต่าง Serial Monitor หรือ Terminal ใน KidBright IDE หรือโปรแกรมอื่นค้างไว้ ให้ปิดหน้าต่างนั้นก่อน เพื่อคืนสิทธิ์การใช้งานพอร์ตให้กับเบราว์เซอร์

Q3: กล้องไม่เปิดทำงาน หรือภาพมืดสนิท

คลิกที่ไอคอนรูปแม่กุญแจ 🔒 ที่แถบที่อยู่ URL ของเบราว์เซอร์ ตรวจสอบว่าได้ตั้งค่าอนุญาต (Allow) การใช้งานกล้องแล้ว และปิดแอปพลิเคชันอื่นที่อาจดึงกล้องเว็บแคมอยู่
