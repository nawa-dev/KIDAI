01.

บทนำและภาพรวมระบบ (Introduction & Overview)

KIDAI (คิดได้) คือสตูดิโอสร้างและทดลองปัญญาประดิษฐ์ (AI Vision) บนเบราว์เซอร์ ที่สร้างขึ้นเพื่อเชื่อมต่อความสามารถด้าน Computer Vision เข้ากับบอร์ดสมองกลฝังตัว KidBright32 โดยตรงผ่านพอร์ต USB ด้วย Web Serial API ที่ความเร็ว 115200 bps

🔒 100% Client-side

รันโมเดลบนเครื่องด้วย TensorFlow.js และ MediaPipe ปลอดภัยสูงสุด

⚡ Direct Web Serial

ส่งข้อมูลผ่านสาย USB สู่บอร์ด KidBright32 ทันทีโดยไม่ต้องลงโปรแกรม Python

🧩 KidBright Plugin

มีปลั๊กอิน ai_serial.zip ให้ติดตั้งลง KidBright IDE ได้ทันที

02.

การติดตั้ง Plugin ในโปรแกรม KidBright IDE

STEP 1
ดาวน์โหลดไฟล์ปลั๊กอิน ai_serial.zip

ดาวน์โหลดไฟล์ ai_serial.zip

STEP 2
เปิด KidBright IDE > Plugins > Install Plugins

เลือกเมนูด้านบนของโปรแกรม KidBright IDE เพื่อนำเข้าไฟล์ปลั๊กอิน

STEP 3
พบบล็อกคำสั่งใหม่

ในแถบเมนูด้านซ้ายจะมีหมวดหมู่ Plugins > AI Serial ปรากฏขึ้นพร้อมใช้งาน

03.

โมเดลจดจำใบหน้า (Face Recognition)

ใช้โมเดล BlazeFace เพื่อตรวจจับและ Crop เฉพาะใบหน้าจริง นำเข้าสู่ MobileNet เพื่อสกัดเวกเตอร์คุณลักษณะ และใช้ KNN Classifier ในการจำแนกประเภทแบบ Real-time พร้อมระบบปฏิเสธคนแปลกหน้า (Unknown Person) ตามค่า Threshold

04.

โมเดลนับจำนวนนิ้ว (MediaPipe Hands)

ตรวจจับข้อนิ้วมือ 21 จุด 3 มิติแบบ 60 FPS นับจำนวนนิ้วที่ชูขึ้น 0 ถึง 5 นิ้ว และส่งผลลัพธ์เป็นตัวเลขเดี่ยวเข้า KidBright32 ทันที เหมาะสำหรับทำโครงงานควบคุมหุ่นยนต์หรือเกมปฏิสัมพันธ์

05.

การเชื่อมต่อ Web Serial API

ทำงานที่ความเร็ว Baud Rate 115200 bps ผ่านสาย Micro-USB Data พร้อมระบบกู้คืนการเชื่อมต่อพอร์ตเดิมให้อัตโนมัติ (Auto Reconnect)

06.

การแก้ปัญหาและคำถามที่พบบ่อย (Troubleshooting & FAQ)

ไม่พบพอร์ต COM?

ตรวจสอบสาย Micro-USB ว่ามีสายสัญญาณ Data หรือไม่ และติดตั้งไดรเวอร์ CP210x / CH340

Port is already open?

ปิดหน้าต่าง Serial Monitor ใน KidBright IDE ก่อนเปิดใช้งานบนเว็บ
